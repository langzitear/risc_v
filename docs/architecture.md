# 设计约定

## 当前实现

仅有独立 PC 模块：32 位，上升沿更新，同步高有效复位，复位地址为 0，非复位周期加 4。
还没有实现取指、指令译码、寄存器堆或 CPU 顶层。

## 第一版 CPU 的计划

- 目标指令集：RV32I，分阶段实现；未完成前不声明完整兼容。
- 微架构：单周期，指令与数据存储器分开。
- 地址按字节定义，数据采用小端序；数组索引必须显式从字节地址转换。
- 第一阶段只支持对齐的 32 位访存，再补齐字节、半字访问。
- 仿真模型先使用组合读，在时钟沿写；这与 FPGA 同步块 RAM 的时序不同，上板前需重新适配。
- 初期不实现特权模式、中断、CSR、MMU、乘除法和压缩指令。
- 未支持指令应在仿真中明确报错，避免静默执行；异常处理机制留到后续设计。

接口发生变化时在这里更新，并同步修改测试。
