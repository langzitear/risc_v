## 下一步：寄存器堆

1. 新建 `rtl/core/regfile.v`：32 × 32 位，两个组合读端口、一个上升沿写端口。
2. 明确 x0 恒为零；测试只读取已写入的普通寄存器，不依赖未初始化值。
3. 新建 `sim/unit/tb_regfile.v`：检查写入、双端口读取、禁止写入 x0。
4. 将测试接入 Makefile 的 `test` 目标，失败时使用 `$fatal`。

## addi 阶段验收程序

```asm
addi x1, x0, 5
addi x2, x1, 3
addi x3, x2, -10
addi x0, x0, 7
```

最终检查 x1=5、x2=8、x3=0xfffffffe、x0=0。
这些指令暂时只是验收计划，目前 CPU 尚未实现。
